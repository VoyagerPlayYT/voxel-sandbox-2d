Полноценная 2D воксельная песочница с процедурной генерацией бесконечных миров по зерну (seed), физикой гранулированных материалов (падающий песок), симулятором жидкостей на клеточных автоматах (вода), динамическим циклом дня и ночи, добычей руд, полевым верстаком крафта и серверным сохранением состояния миров в базу данных SQLite.

## Технологический стек и возможности

- **Процедурная генерация биомов:** Многооктавные гармонические синусоиды для рельефа, генератор пещерных жил, стратифицированное залегание полезных ископаемых (уголь, железо, золото, алмазы), генерация деревьев с лиственными кронами и песчаных побережий.
- **Физический симулятор (Cellular Automata):**
  - Реальная физика сыпучего песка: падение вниз при отсутствии опоры и соскальзывание под углом 45 градусов по склонам.
  - Распространение воды: стекание в низины и горизонтальное выравнивание давления между соседними ячейками.
- **Физика игрока (AABB Kinematic Body):** Честный расчет коллизий твердых блоков по горизонтали и вертикали, ускорение, прыжки, гравитация, плавное следование камеры.
- **Добыча и строительство:** Расчет досягаемости (reach range), время разрушения в зависимости от твердости блока и используемого инструмента (деревянная/каменная кирка, топор), выпадение блоков в инвентарь.
- **Хотбар и верстак крафта:** 9 слотов быстрого доступа, рецепты создания досок, палок, факелов, каменных кирпичей и улучшенных инструментов.
- **Серверный бэкенд на FastAPI + SQLite:**
  - Полный CRUD для управления мирами: создание по уникальному сиду, сохранение координат игрока, времени суток, содержимого инвентаря.

## Зачем этому проекту нужен выделенный домашний сервер 24/7 (HP ProLiant DL360 Gen9)

1. **Постоянная персистентность миров и чанков:** Сервер корпоративного уровня HP ProLiant DL360 Gen9 с аппаратным RAID-контроллером Smart Array и SSD-накопителями гарантирует сохранность созданных воксельных миров и исключает повреждение файлов баз данных даже при резких отключениях питания.
2. **Фоновая симуляция и синхронизация:** Выделенный сервер берет на себя хранение больших матриц блоков и позволяет продолжать исследование с любого семейного ноутбука или браузера в локальной сети без переноса файлов сохранений вручную.
3. **Бесперебойный доступ 24/7:** Миры всегда доступны по фиксированному IP в локальной сети домохозяйства.
4. **Высокая плотность ресурсов:** 32–64 ГБ ECC DDR4 памяти сервера позволяют легко удерживать в кэше базы данных десятки сгенерированных миров одновременно.
